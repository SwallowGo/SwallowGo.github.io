Solidity Storage Layout 原理（Compiler 是如何布局 Storage 的）

一、核心思想

Storage Layout 不是人为规定的，而是 Compiler 根据固定规则推导出来的。

Compiler 的目标不是：

  • 节省空间
  • 提高性能

而是：

保证 Storage Layout 永远稳定（Deterministic）。

因为链上的数据一旦部署，就不能修改。

所以：

Storage Layout 必须保证：

  • 每一次编译结果一致
  • 每一次读取的位置一致
  • 后续升级不能破坏已有数据
